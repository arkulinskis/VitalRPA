Paste this just before </body> on every page (your theme's footer is usually the one place). It adds visitors, real page-load times and JavaScript errors.

Where to paste it

    

      
WordPressAppearance → Theme file editor → footer.php before </body>, or any "header & footer scripts" plugin.

      
ShopifyOnline Store → Themes → Edit code → theme.liquid, just before </body>.

      
Wix, Squarespace, WebflowSettings → Custom code → "Body end" / "Footer", on all pages.

      
Google Tag ManagerNew tag → Custom HTML → paste → trigger "All pages".

      
Single-page appsAfter each route change, call vrpa({t:"v"}) to count the new page.

      
Several sitesEach site has its own key. Watching another site? Add it in the console and copy its snippet.
